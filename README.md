# 🎮 NEXUS — Gaming Command Center

NEXUS is a modern, futuristic gaming command center built with React and Vite. It provides a centralized interface for discovering games, tracking gaming progress, viewing achievements, managing friends, and launching interactive game experiences.

---

## 🚀 Project Overview

NEXUS combines a gaming dashboard with a modern gaming platform UI.

### Main Features

- 🎮 Futuristic gaming landing page
- 🔐 Player login and demo login
- 📊 Gaming dashboard
- 🎯 Game discovery
- 📚 Personal game library
- 🏆 Achievements tracking
- 👥 Friends section
- 🔔 Notifications
- ⚙️ Settings
- 🎮 Interactive game player
- 📈 Gaming activity chart
- 🌓 Theme toggle
- 📱 Responsive mobile layout
- 📌 Fixed mobile navigation
- ✨ Smooth animations
- 🎨 Modern glassmorphism UI
- 🔍 Game search
- 🎯 Game progress tracking
- 🔥 Featured and popular games
- 💾 LocalStorage authentication
- 📱 Mobile-friendly controls
